# 슬라이드 디자인 시스템: 깔끔한 틸(Teal) 레이아웃

슬라이드 제작을 위한 디자인 참고 문서입니다. 출처: "깔끔한 레이아웃 테마 PPT" 템플릿 이미지 (샘플 슬라이드 15장).

## 1. 톤

깔끔하고 기업적이며 신뢰감 있는 분위기. 플랫 벡터 스타일, 넉넉한 여백, 하나의 주도적인 틸 색상에 노란색 포인트 하나.

## 2. 색상

| 역할 | HEX | 용도 |
|------|-----|-------|
| 주색 틸 | `#00877A` | 제목 바, 핵심 도형, 표지/마지막 슬라이드 배경 |
| 진한 틸 | `#006B63` | 그림자, 겹친 도형, 밝은 배경 위 제목 |
| 연한 틸 | `#4DB6AC` | 보조 도형, 링, 차트 막대 |
| 아주 연한 틸 | `#E0F2F1` | 부드러운 패널, 아이콘 원 |
| 포인트 노랑 | `#F5B700` | 강조 전용 (도넛 일부, 활성 점) |
| 네이비 | `#1F3A6E` | 드물게 쓰는 강조 제목 글자 |
| 진회색 | `#333333` | 본문, 흰 배경 위 제목 |
| 중간 회색 | `#808080` | 보조 텍스트, 차트 막대, 캡션 |
| 연회색 | `#F2F2F2` | 내용 슬라이드 배경 패널 |
| 흰색 | `#FFFFFF` | 기본 배경, 틸 위 글자 |

규칙: 틸 계열이 색상 사용의 약 80%, 노랑은 5% 미만, 다른 색상은 추가하지 않습니다.

## 3. 타이포그래피

- 한글: **Noto Sans KR** (대체: 맑은 고딕). 영문: 같은 폰트 또는 Arial.
- 제목: 28-36pt, Bold. 표지 제목은 최대 40pt.
- 섹션/항목 제목("메인 타이틀"): 16-20pt, Bold.
- 본문: 11-14pt, Regular, 진회색. 최소 10pt.
- 캡션/푸터: 8-10pt, 중간 회색.
- 틸 위의 글자는 흰색, 흰색/회색 위의 글자는 진회색.
- 슬라이드당 굵기는 최대 2종류 (Bold + Regular).

## 4. 레이아웃

- 비율 16:9 (13.333 x 7.5 in). 사방 여백 최소 0.5 in.
- 헤더: 슬라이드 제목은 좌상단 또는 상단 중앙, 아래에 얇은 회색 부제 줄, 우상단에 작은 로고(다이아몬드 마크 + "MY LOGO").
- 푸터: 하단에 작은 로고 또는 URL, 하단 가장자리에 틸 띠(선택).
- 12칼럼 그리드를 사용하고 내용 블록은 정렬과 간격을 균일하게 유지합니다.
- 슬라이드당 메시지 하나, 반복 항목(아이콘, 단계, 칼럼)은 최대 6개.

### 슬라이드 유형

| 유형 | 구성 |
|------|------|
| 표지 | 왼쪽 흰 영역에 제목 + 부제 + URL, 오른쪽/상단에 큰 물결 모양 틸 도형 |
| 마지막 | 전체 틸 배경, 중앙에 흰색 "Thank You", 더 밝은 물결 띠 |
| 허브/순환 | 중앙 원 하나와 얇은 선으로 연결된 4-6개 위성 항목, 각각 아이콘 + 제목 + 2줄 텍스트 |
| 단계/프로세스 | 가로 또는 세로로 3-6개 번호 항목 (원, 리본, 화살표, "STEP 01") |
| 리본 배너 | 접힌 끝을 가진 틸 리본 안에 슬라이드 제목 |
| 비교/목록 | 왼쪽 틸 라벨, 오른쪽 아이콘 + 텍스트, 또는 2x2 아이콘-텍스트 격자 |
| 차트 | 틸 + 회색의 단순 막대/도넛 차트, 강조 값만 노랑, 큰 숫자(01, 02, 03) |
| 기기 목업 | 모니터 또는 휴대폰 이미지 옆에 2-3개 텍스트 항목 |

## 5. 도형과 아이콘

- 단색 채우기만 사용: 1pt 초과 외곽선 금지, 그라데이션 금지, 은은한 그림자까지만 허용.
- 표지와 마지막 슬라이드는 물결/유기적 곡선, 내용 슬라이드는 직선 사선 띠.
- 아이콘과 단계 번호는 원형, 아이콘은 틸 원 위의 단순한 흰색 선/글리프 아이콘.
- 구분선: 얇은 0.75pt 회색 선.

## 6. 해야 할 것 / 하지 말아야 할 것

- 텍스트는 짧게 (제목 20자 이내, 설명 2줄 이내).
- 모든 내용 슬라이드에서 간격, 정렬, 반복되는 헤더/푸터를 일관되게 유지.
- 틸 + 회색 + 노랑 포인트 하나 외의 색을 쓰지 않기.
- 텍스트가 도형 밖으로 넘치거나 다른 요소와 겹치지 않게 하기.
- 장식용 클립아트나 배경이 복잡한 사진 사용 금지.
