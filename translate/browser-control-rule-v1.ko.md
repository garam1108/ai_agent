# 브라우저 제어 규칙 v1 (한글 번역본)

Playwright MCP(`mcp__playwright__*` 도구)로 웹 브라우저를 제어할 시점을 정하는 규칙입니다.

## 1. 자동 호출 (키워드 트리거)

- 사용자의 채팅에 트리거 키워드가 포함되어 있으면, 확인을 묻지 않고 Playwright MCP를 자동으로 호출합니다.
- 트리거 키워드 (한글/영어 변형):
  - 브라우저를 열어서 작업 / 브라우저 열어서 / 브라우저를 열어
  - 웹 제어 / 웹 브라우저 제어
  - 직접 작업 / 직접 해줘
  - open the browser / control the browser / control the web / work in the browser
- 정확히 같은 문구만이 아니라 의미로 판단합니다 (예: "브라우저로 직접 들어가서 해줘"도 해당).

## 2. 동의 후 호출 (키워드 없음)

- 사용자가 트리거 키워드를 쓰지 않았더라도 Playwright MCP가 분명히 도움이 되는 경우(예: 실제 웹 페이지가 필요한 작업, 폼 입력, 클릭, 스크린샷, 렌더링된 페이지 확인), 먼저 사용자에게 동의를 구합니다.
- 브라우저 제어가 왜 도움이 되는지, 무엇을 할 것인지 간단히 설명합니다.
- 사용자가 동의한 뒤에만 Playwright MCP를 호출합니다. 거절하면 다른 방법을 사용합니다.

## 3. 작업 수칙

- Playwright MCP 도구를 호출하기 전에 ToolSearch로 스키마를 로드합니다.
- 페이지 이동 후 상호작용하기 전에 `browser_snapshot`으로 페이지 상태를 확인합니다.
- 브라우저 대화상자가 예기치 않게 뜨는 동작은 피하고, 뜨면 `browser_handle_dialog`로 처리합니다.
- 사용자의 명시적 승인 없이 외부 서비스에서 폼 제출, 구매, 메시지 전송을 하지 않습니다.
- 작업이 끝나면 브라우저를 닫고(`browser_close`) 결과를 사용자에게 보고합니다.
