# CLAUDE.md (한글 번역본)

## 사용자

- 이름: 가람

## 언어 규칙

- 사용자가 영어, 한글 등 어떤 언어로 질문하더라도 답변은 항상 한글로 작성합니다.

## 마크다운 파일 규칙

- 모든 `.md` 파일은 영어로 작성합니다.
- 작성한 모든 `.md` 파일의 한글 번역본을 `C:\Users\SBS\Desktop\ai_agent\translate`에 `<원본 이름>.ko.md` 형식으로 저장합니다 (예: `CLAUDE.md` -> `translate/CLAUDE.ko.md`).
- 번역본을 항상 원본과 동기화합니다.
  - `.md` 파일이 수정되면 변경된 부분을 확인하고 같은 내용을 번역본에도 반영합니다.
  - `.md` 파일이 삭제되면 해당 번역본도 함께 삭제합니다.
  - `.md` 파일을 건드린 작업을 마치기 전에 `translate` 폴더가 현재 상태와 일치하는지 확인합니다.
